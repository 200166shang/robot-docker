# Domain Docs

This is a single-context repository.

## Before exploring

When they exist, read:

- `CONTEXT.md`
- relevant files under `docs/adr/`

If these files do not exist, proceed without creating them automatically.

## Lazy creation

Create `CONTEXT.md` when the repository develops stable domain terminology.

Create an ADR under `docs/adr/` when the project makes a durable architectural decision that future work should preserve.

## Vocabulary

When `CONTEXT.md` exists, use its terminology in Issue titles, specifications, documentation, and code comments.

If a new term is ambiguous or overloaded, resolve it before implementation and record the decision when it becomes durable.
